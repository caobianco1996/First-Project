# First Project

Exercício de Angular sobre componentes, data binding e criação de uma lista simples de servidores.

## Executar

```sh
npm ci
npm start
```

Abra `http://localhost:4200`. Para gerar uma versão de produção, use `npm run build`; para testes unitários, `npm test`.

O projeto usa Angular 13 e serve como material de aprendizagem. Os estados e servidores ficam somente em memória; não existe backend ou persistência.

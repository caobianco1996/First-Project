# Lista de servidores — exercício Angular

Aplicação didática Angular 13 sobre componentes, data binding e uma lista simples de servidores. Os dados existem somente em memória; não há backend nem persistência.

## Requisitos

- Node.js compatível com Angular CLI 13
- npm

## Instalar e executar

Na raiz do repositório:

~~~sh
npm ci
npm start
~~~

Abra http://localhost:4200.

## Build e testes

~~~sh
npm run build
npm test
~~~

O teste abre o runner Karma; pode ser necessário ter um navegador compatível instalado. Para conferir manualmente, adicione um servidor pela interface, altere seu estado e atualize a página para observar que os dados não persistem.

## Escopo

Este projeto é um exercício de front-end. Ele não salva os dados em um servidor ou banco de dados.
